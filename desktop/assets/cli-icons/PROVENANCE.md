# CLI icons and sidebar reference

CLI icon assets are retained from Herdr App `4deb605f0b3d25d409c80cff9082d5c19a043ea8`, `defaults/icons/`. Agent marks originate from LobeHub icons (MIT); the generic agent glyph is from Lucide (ISC/MIT). Full notices are included beside the icons. Product names and marks remain their owners' trademarks; these licenses do not grant trademark rights.

The native sidebar independently implements the compact row, expandable descendant tree and branch-line layout reviewed in `defaults/mods/agents/main.js` at that revision (Herdr App, Apache-2.0). It preserves Dauerbot's GPUI frontend and legacy HERDR 0.9.5 transport. No reference backend or lifecycle behavior is imported.
